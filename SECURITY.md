# Security

This project is an early, limited review aid. It does not certify app security or execute inspected projects. Reports can contain private paths/component names; inspect them before sharing.

For a tool vulnerability, use the repository's private vulnerability reporting feature if enabled. If it is unavailable, open a minimal issue requesting a private contact channel without exploit details or sensitive data. No private contact address is configured yet.

Do not include real credentials, private APKs, customer data, or findings against third-party apps in public issues. Use a minimal synthetic reproduction.
